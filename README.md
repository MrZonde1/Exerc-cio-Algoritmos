# Cálculo de Média e Maior Média de Alunos em C++

Este repositório contém um algoritmo desenvolvido em C++ para cadastrar notas de alunos, calcular suas médias individuais, determinar o status de aprovação e identificar o aluno com o melhor desempenho da turma.

## 📌 Funcionalidades

- **Cadastro Limitado:** Suporta a inserção de dados de até 6 alunos.
- **Cálculo de Média:** Utiliza uma função dedicada (`calcularMedia`) para processar as 3 notas de cada aluno.
- **Relatório Completo:** Exibe uma tabela organizada com as notas, a média final e a situação (`Aprovado` para média $\ge 7.0$ ou `Reprovado`).
- **Destaque da Turma:** Identifica e exibe ao final o nome e a média do aluno com o maior desempenho.

## 🚀 Como Executar o Projeto

### Pré-requisitos
- Compilador de C++ instalado (como `g++`) ou um ambiente como o VS Code, Dev-C++ ou GDB Online.
